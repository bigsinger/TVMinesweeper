设备为 `emulator-5554`，Android 9 / API 28，物理显示 1080×1920，游戏横屏实际为 1920×1080。

`tools/verify-device.ps1` 检查新局随机雷数范围、READY / PLAYING 存档雷数保留、三档边界、单击插旗与取消、双击翻开和旗帜保护、长按去重、移动取消待执行单击、首次 3×3 安全、音量键不改变棋盘、Menu / M / F1 菜单、菜单和后台暂停及恢复。脚本保留排行榜，结束后恢复初级空白新局。

1.0.7 完整回归 83 项断言全部通过，日志位于 `E:\temp\TVMinesweeper\device-report-20260919-214443.txt`。三档难度均经返回键暂停菜单进入；验证默认 OK 继续、切换到难度菜单后取消保留棋盘、旗帜、雷数、光标和累计用时，并验证两个菜单停留期间持续暂停计时。全部 46 项 JUnit 和 release Lint 已在 1.0.7 重新执行通过。

另补测暂停菜单第三项“保存并退出”：正常关闭应用，重新启动后保留原棋盘及旗帜。收尾恢复初级空白新局，当前应用进程未发现 AndroidRuntime 崩溃或 TVMinesweeper 警告日志。

1.0.6 完整回归 62 项断言全部通过，日志位于 `E:\temp\TVMinesweeper\device-report-20260919-204642.txt`。设备实际随机雷数示例为初级 12 / 14、中级 49 / 42、高级 104；媒体音量测试后恢复原值。

1.0.6 补测通过：TV 内容菜单键码 256、媒体上下文菜单键码 257、手柄 Start 键码 108 均单次打开 / 关闭菜单；长按 Menu 不重复开关；双击触发结算后的第三次 OK 不误开下一局，稍后单击可正常选择查看棋盘。模拟器结果不代表实体遥控器 Menu 已解决；用户确认实体 Menu 仍无效，因此 1.0.7 增加返回键暂停菜单的独立难度入口。
