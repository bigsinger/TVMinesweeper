# 实现说明

## 规范与原型的应用

本项目以原始开发规范与 HTML 原型为起点，参考 TVTetris 的原生绘制、单一棋盘焦点、按键统一分发、生命周期暂停和短音效实现。保留深色背景、青绿色焦点、真实本机排行榜和居中菜单。

用户最新要求优先于原始输入：单击 OK 插旗、双击 OK 翻开；每局随机雷数；MENU 增加 M / F1 兼容；布局使用实际 2 像素外边距。原始规范与原型作为历史输入保留，未回写修改。

工程仅使用 Git `main` 主分支、纯 Java 和 Android 原生 Framework，没有 AndroidX、NDK、JNI 或第三方运行时依赖。

## 按键与双击

正常棋盘中，单击 OK 切换旗帜，双击 OK 翻开格子或对数字格执行快开。双击窗口为 360ms，单击任务在 361ms 后执行，避免窗口内第二次按下之前先插旗。时钟与调度器可注入，单元测试可精确验证边界、取消和重复按键。

移动光标、切换弹层、退后台等操作取消待执行单击，避免作用到其他格子。长按 OK 的重复事件被忽略。难度菜单、帮助、结算和暂停菜单中，OK 立即确认；暂停状态中，OK 立即继续；查看已结束棋盘时，单击 OK 立即重开。

Activity 与 Dialog 共用 `KeyHandler`。菜单支持 MENU、设备设置键、键盘 M / F1，并兼容只发出 MENU 抬起事件的设备。使用 `KeyEvent.downTime` 识别同一次菜单按键，焦点切换不清除配对状态，避免按下打开后抬起又关闭。结算面板刚出现的 360ms 内忽略残余确认，防止快速三连击误开新局。音量键交由系统处理，不改变棋盘。

返回键提供独立于 MENU 的暂停菜单入口，标题为“游戏已暂停”，默认选中“继续游戏”，其后依次为“选择难度”“保存并退出”。选择难度复用现有难度与设置弹层，转入前后持续暂停计时；只有确认具体难度才创建新局，取消则保留原棋盘、雷数、光标和累计用时。此入口用于实体遥控器无法传入 MENU 事件时，原有 MENU / M / F1 支持仍保留。

## 随机雷数与游戏规则

| 难度 | 列 × 行 | 每局雷数（包含端点） |
| --- | ---: | ---: |
| 初级 | 9 × 9 | 10–15 |
| 中级 | 16 × 16 | 40–50 |
| 高级 | 30 × 16 | 90–110 |

创建新局时使用可注入的 `Random` 在对应范围内抽取一次雷数，保存为该局固定状态。暂停、第一次翻开、菜单开关和存档恢复不会重抽；恢复 READY 状态也必须使用保存的雷数。相邻两局抽到相同数量是允许的，测试不将“每次必须不同”作为条件。

雷的位置推迟到首次翻开时生成，排除首次落点及周围八格，棋盘边缘仅排除实际存在的相邻格。使用有界洗牌布雷与显式队列展开，不进行深递归。旗帜数上限、剩余雷数、安全格总数和胜利判断都基于本局实际雷数。

双击已插旗格不会翻开；需先单击撤旗。双击数字格时，只有周围旗帜数与数字匹配才展开其他相邻格；旗数正确但位置错误仍可能踩雷。打开全部安全格才获胜，通关时自动标记地雷。

## 大屏布局

单个 `BoardView` 负责绘制三栏界面：排行榜、信息栏、棋盘。按 1920 × 1080 设计尺寸，排行榜宽 316 像素，信息栏宽 232 像素，两栏之间留 12 像素，整屏四周外边距固定为设备实际 2 像素。辅助栏随画面比例缩放，棋盘使用剩余区域。

排行榜加宽后，日期与耗时在同一行展示；信息栏集中显示本局实际雷数、剩余雷数、用时、难度、菜单入口和操作提示。棋盘使用约 1020 像素的设计高度，1080p 下初级单格约 113.3 像素、中级约 63.75 像素、高级约 44.13 像素，实际以屏幕比例和可用区域计算。

焦点始终属于棋盘，辅助栏不参与遥控器焦点移动。菜单采用原生 Dialog / TextView；鼠标或触屏点击难度区域打开同一菜单。由于外边距缩小为 2 像素，电视应关闭过扫描以显示完整边缘。

## 模块职责

| 模块 | 职责 |
| --- | --- |
| `game/GameEngine`、`Cell` | 纯 Java 规则、每局随机雷数、首步安全、迭代展开、胜败判断和存档校验 |
| `tv/KeyHandler` | Activity / Dialog 共用的方向、OK、菜单及返回按键入口 |
| `tv/DoubleClickDetector` | 可注入时钟与调度器的单击 / 双击检测 |
| `tv/BoardView` | 大屏绘制、光标、数字、雷旗图形、排行榜、无障碍状态和可选触摸 |
| `ui/GameActivity` | 状态转换、计时、生命周期、菜单和异步存档协调 |
| `ui/DifficultyDialog` | 难度、音效、帮助、结算和暂停菜单弹层 |
| `data` | 本地设置、完整对局快照、真实胜利前八名 |
| `util/SoundEffects` | 原创短 WAV 加载、限频播放、静音、后台停止和资源释放 |

## 保存、计时与积分

棋盘、该局固定雷数、计时和光标作为同一个快照保存到应用私有 SharedPreferences。恢复校验尺寸、雷数、已开格、旗帜和胜败状态；异常存档回退为新局。读写由后台执行器协调，`apply` 异步落盘。正常生命周期退出前安排最终保存，不把后台运行时间计入成绩。

计时从第一次翻开开始，难度菜单、暂停菜单、外部失焦和后台期间暂停。返回前台显示暂停遮罩，OK 继续不额外插旗或翻格。音效为离线合成的短 WAV，无循环背景音乐；后台与关闭音效时停止声音。

仅将真实胜利写入本机前八名，不写入演示、失败或未完成成绩。积分沿用 `round(难度权重 × 10000 / max(秒数, 1))`，初、中、高级权重分别为 1、3、8；雷数随机范围不改变这套积分公式。

## 构建与验证

编译与目标 API 为 28，最低 API 为 18；AGP 4.2.2、Gradle 6.9.4、JDK 11。纯 Framework 方案不需要 support、MultiDex 或核心 Java 库脱糖；高版本 Android API 使用版本判断。没有 `.so`，同一 APK 可用于 arm64 电视及当前模拟器，不额外构建其他 ABI 原生库。

release 开启 R8 / ProGuard 与签名，自动增加版本号并输出到项目根 `release`。具体环境和签名管理见[构建说明](构建说明.md)。

`tools/verify-device.ps1` 从中文无障碍状态读取棋盘状态、光标、已开数、旗帜、用时、暂停状态和实际雷数，检查按键、边界、首开 3×3、安全插旗、返回菜单默认继续、经返回入口选择难度及取消保留原局、菜单快捷键、计时暂停和存档恢复。新局统一经返回 → 选择难度进入，同时独立检查 MENU / M / F1 开关菜单；暂停菜单和难度菜单之间的转换也验证不累计停留时间。脚本默认保留数据但会重开测试对局，显式 `-ResetData` 才清除数据；结束恢复初级新局。

音量按键检查会先读取并在测试后恢复原媒体音量，无法可靠读取时只校验源码未拦截。精确 360ms 时间边界由 JVM 单测验证；可选 `-SlowDoubleClick` 额外执行设备 `sleep 0.32` 慢双击，实际间隔还包含设备命令启动耗时，应结合单测和设备表现分析。脚本报告与 XML 临时文件仅写入 `E:\temp\TVMinesweeper`，不截图、不修改分辨率。通过数量由实际运行报告给出。

中文 PowerShell 回归脚本保存为 UTF-8 BOM 以兼容 Windows PowerShell 5.1；所有 Markdown 使用 UTF-8、LF。发布私钥保存在 `E:\temp\TVMinesweeper`，清理临时目录前需备份，仓库不保存私钥或密码。
