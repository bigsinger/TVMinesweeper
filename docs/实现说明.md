# 实现说明

## 规范与原型的应用

本项目以 `docs` 原始规范与 HTML 原型为依据，采用左侧本机积分榜、相邻信息侧栏、右侧大棋盘的三栏布局，保持深色背景、青绿色焦点与居中难度弹层。时间、剩雷、难度和操作提示集中在窄信息侧栏，优先给棋盘和数字留出显示空间。开发经验参考同目录下的 TVTetris：采用轻量原生绘制、单一棋盘焦点、遥控器统一处理、生命周期暂停及短音效反馈。

用户本次指令优先于原始规范：仅使用现有 Git `main` 分支，不创建 develop / feature 等分支；构建保持纯 Java、无 AndroidX、无 NDK 和无第三方运行时依赖。

## 必要调整

1. 原规范的单击延迟 240ms 小于双击窗口 280ms，会造成 240–280ms 内第二次按键前已经翻开格子。实现统一为双击窗口 280ms、单击延迟 281ms，取消三连击多余动作；移动、菜单、音量键及退后台都会取消待执行单击。
2. 基于电视固定横屏和最多 480 格的小棋盘，采用单个 `BoardView` 绘制棋盘和侧栏，替代原规范示例中的大量格子 View / ListView。焦点始终保留在棋盘，排行榜和信息侧栏不会抢焦点。所有数字、文字和形状随画面整体缩放，720p / 1080p 均保留内容安全边距；菜单使用原生 Dialog 和 TextView。
3. 无 AndroidX，也无需 support、MultiDex 或核心 Java 库脱糖。代码仅用 API 18 可用的 Java / Android API，沉浸模式在 API 19 以上才启用。编译和目标 API 均为 28。
4. Gradle 采用本机可用的 6.9.4 维护版本，AGP 仍为规范要求的 4.2.2，JDK 11。国内镜像、自动版本、签名和 release 交付规则见构建说明。
5. 不生成 native 库，也不存在 ABI 专属二进制。因此同一纯 Java APK 可用于 arm64 电视，并可安装到当前雷电模拟器进行验证；没有额外构建 x86 或 arm32 版本。

## 画面布局与可读性

两条窄侧栏并排放在左侧：排行榜展示通关成绩，信息侧栏展示时间、剩余雷数、当前难度、MENU 按钮和操作提示。右侧棋盘充分利用屏幕高度，保持清晰的格线、彩色数字和高亮光标。遥控器按 MENU 打开难度菜单；鼠标或触屏也可点击信息侧栏的难度区域。

按 1920 × 1080 设计尺寸计算，棋盘可用高度达到 896 像素，三种难度的单格边长均比原布局更大：

| 难度 | 原单格边长 | 当前单格边长 |
| --- | ---: | ---: |
| 初级 | 65 像素 | 约 99.6 像素 |
| 中级 | 39 像素 | 56 像素 |
| 高级 | 39 像素 | 约 42.7 像素 |

这些尺寸随实际屏幕等比缩放，720p 和 1080p 都保留 5% 安全边距。集中展示辅助信息的目的，是让玩家坐在电视前更容易辨认棋盘和当前落点。

## 模块职责

| 模块 | 职责 |
| --- | --- |
| `game/GameEngine`、`Cell` | 纯 Java 规则、注入随机源、迭代展开、胜败判断、严格校验的棋盘序列化 |
| `tv/KeyHandler` | Activity / Dialog 共用的方向、OK、音量、菜单、返回按键入口 |
| `tv/DoubleClickDetector` | 可注入时钟和调度器的单击 / 双击检测，可直接用 JUnit 测试 |
| `tv/BoardView` | 大屏绘制、光标、数字、雷 / 旗图形、真实排行榜和可选触摸 |
| `ui/GameActivity` | 游戏状态转换、计时、生命周期、菜单和异步存档协调 |
| `ui/DifficultyDialog` | 难度 / 音效 / 帮助 / 结算 / 退出确认的遥控器弹层 |
| `data` | 本地设置、完整快照、真实胜利前八名 |
| `util/SoundEffects` | 原创短 WAV 加载、限频播放、静音、后台停止和资源释放 |

## 规则与存储

首次翻开时才布雷，排除落点及周围八格。使用有界部分洗牌选雷，空白区域使用显式队列展开。旗帜最多与雷数相同，防止剩余雷数为负。正确旗数对应数字时可以快速展开；旗数正确但位置错误仍可能踩雷。

只有打开全部安全格才获胜。通关时自动标记地雷，按原型公式 `round(难度权重 × 10000 / max(秒数, 1))` 积分，初 / 中 / 高权重为 1 / 3 / 8。无演示数据，不把失败或未完成的局计入排行榜。

棋盘、计时和光标作为同一个快照保存在应用私有 SharedPreferences，设置与榜单同样在本地保存。读写协调使用后台执行器，Android 的 `apply` 异步落盘。存档恢复验证版本、尺寸、雷数、已开格、旗帜和胜败状态，坏档回退为新局。

计时从第一次翻开开始，菜单、退出确认、外部失焦及后台期间暂停。返回前台显示暂停遮罩，OK 继续时不会额外翻格。声音为离线合成的短小 WAV，无背景循环音乐；后台和关闭音效时立即停止旧声音。

## 资源与维护

所有面向用户的文本在中文 / 英文 `strings.xml` 中。图标和 TV banner 由 `tools/generate-artwork.ps1` 绘制。release 私钥位于用户指定的 `E:\temp\TVMinesweeper`，应在清理临时目录前自行备份，仓库不保存私钥或密码。
