# TVMinesweeper 使用帮助

TVMinesweeper 是适合电视遥控器操作的经典扫雷游戏。画面从左到右依次为积分排行榜、窄信息侧栏和大棋盘。剩余雷数、用时、难度和操作提示集中在排行榜旁的信息侧栏，让右侧棋盘充分利用屏幕高度，格子和数字更方便远距离看清。

游戏支持 Android 4.3 及以上系统，横屏运行，无需联网，不申请网络等权限。

## 安装和启动

1. 在项目根目录的 `release` 文件夹找到 `TVMinesweeper-release-版本号.apk`。
2. 将 APK 复制到电视或电视盒子，使用设备的文件管理器安装。开发调试也可执行 `adb install -r APK文件路径`。
3. 在电视应用列表中打开“电视扫雷”。首次开始时使用初级难度，光标位于棋盘左上角。

APK 使用纯 Java 实现，不包含原生 `.so` 库，不需要额外的 ABI 安装包。覆盖安装会保留本机设置、排行榜和已保存的进度；卸载或清除应用数据会删除这些内容。

## 遥控器操作

| 按键 | 棋盘中的作用 |
|---|---|
| 上、下、左、右 | 移动高亮光标，棋盘边缘不会绕回 |
| OK / 确认键单击 | 翻开当前格子；已翻开的数字格满足条件时可快速展开周围格子 |
| OK / 确认键快速双击 | 给当前未翻开的格子插旗，再次双击取消旗帜 |
| 音量 + 或音量 − | 插旗或取消旗帜，与 OK 双击作用相同 |
| MENU / 菜单键 | 打开难度和设置菜单 |
| 返回键 | 打开退出确认；默认选中继续游戏 |

双击的两次按下需要在约 280 毫秒内完成。为区分单击和双击，单击翻开会有短暂等待，请勿连续乱按。长按 OK 不会反复操作，也不作为插旗方式。

键盘调试时，Enter 对应 OK，Esc 对应返回。兼容手柄的 A 确认、X 插旗、Start 菜单、B 返回；设备的设置键也可用于打开菜单，前提是系统允许该按键传入应用。

部分电视遥控器的音量键通过红外直接控制电视，游戏无法收到按键。遇到这种情况，请使用 OK 双击插旗。游戏收到音量键时会用于插旗；如需调整设备音量，可先在电视系统中调整，再返回游戏。

## 三分钟学会扫雷

1. 选择一个格子，单击 OK 开始。第一次翻开的格子以及它周围的八格不会放置地雷；棋盘边缘以实际存在的相邻格子为准。
2. 格子中的数字表示周围八格里一共有多少颗雷。空白格周围没有雷，会自动展开相连的安全区域。
3. 推断某个未翻开的格子有雷时，双击 OK 给它插旗。已经插旗的格子不会被单击翻开；需要先取消旗帜。
4. 当一个已翻开的数字格周围旗帜数等于该数字时，单击该数字格可一次翻开其余相邻格子。请先确认旗帜位置正确，错误插旗可能在快速展开时踩雷。
5. 翻开全部没有地雷的格子即为通关，不要求给所有地雷插旗。翻开任意地雷则本局结束。

“剩余雷数”根据地雷总数减去旗帜数量计算，旗帜只是你的标记，不代表系统已确认那里有雷。除首次安全区域外，扫雷仍可能遇到需要判断或尝试的局面。

旗帜数量最多等于本局地雷总数。如果剩余雷数已经为零，需先取消一面旗帜，才能在其他位置插旗。

## 选择难度和设置

按遥控器 MENU 打开菜单，用上下方向键选择，按 OK 确认。使用鼠标或触屏时，也可以点击信息侧栏中的难度区域或 MENU 按钮。菜单打开期间暂停计时。再次按 MENU 或返回键关闭菜单，光标保持在原位置。

| 难度 | 棋盘尺寸（列 × 行） | 地雷数 | 适合 |
|---|---:|---:|---|
| 初级 | 9 × 9 | 10 | 熟悉规则和遥控器操作 |
| 中级 | 16 × 16 | 40 | 练习数字推理 |
| 高级 | 30 × 16 | 99 | 挑战复杂局面和通关速度 |

确认任一难度会立即开始该难度的新局，替换当前棋盘；选择相同难度也会重新开局。只想返回当前棋盘时，请选择“继续游戏”，或按 MENU / 返回取消。

菜单还提供音效开关和玩法帮助。音效包括移动、翻开、插旗、取消旗帜、菜单、通关和踩雷的短提示音，不循环播放背景音乐。关闭音效会立即停止当前声音，并保存设置供下次启动使用。

## 暂停、继续和结束

- 打开菜单、退出确认或切到其他应用时，游戏暂停计时。应用进入后台也会停止音效。
- 返回应用后，如果出现暂停提示，按 OK 继续。暂停期间不会累计游戏用时。
- 游戏保存当前棋盘、累计用时和光标位置。正常退出后再次打开，可继续已保存的未结束对局。
- 通关或踩雷后会显示结算面板。可选择“再来一局”开始同难度的新游戏，或选择“查看棋盘”查看本局结果；查看棋盘时可以用方向键移动、单击 OK 再开一局，按 MENU 可重新选择难度。
- 返回键打开退出确认后，选择继续可回到本局；选择退出后关闭应用。

## 积分排行榜

排行榜只保存本机真实通关的前八名，不含演示数据。失败或尚未结束的对局不计入排行榜。进入前八名的新成绩会在列表中高亮提示。

积分按以下方式计算：

```text
积分 = 四舍五入（难度权重 × 10000 ÷ 通关用时秒数）
```

初级、中级、高级的难度权重分别为 1、3、8，不足一秒按一秒计算。同难度下用时越短，积分越高。排行榜首先按积分从高到低排列；积分相同则优先用时较短的成绩，用时也相同则优先最近完成的成绩。

菜单和后台暂停时间不计入通关用时。排行榜条目显示积分、难度、用时和日期，仅保存在本设备，不会上传。

## 常见问题

**单击 OK 为什么稍等一下才翻开？**

游戏需要等待短暂的双击判定窗口，这样才能让同一个确认键同时支持翻开和插旗。

**为什么格子按 OK 没反应？**

可能该格已插旗，需先双击取消；也可能已经翻开，而周围旗帜数不满足快速展开条件。若当前处于菜单、结算或暂停界面，请先根据界面提示操作。

**没有音效怎么办？**

先检查菜单中的音效开关和电视媒体音量。应用刚启动时音频需要短暂加载；尚未加载完成的音效会被略过，不影响操作。

**左右方向键会移动到排行榜吗？**

不会。排行榜和信息侧栏不抢占棋盘焦点，方向键始终在棋盘内部移动；选择难度时直接按 MENU 即可。

**电视边缘显示不完整怎么办？**

界面已预留电视安全边距。如果仍被裁切，请在电视显示设置中关闭过扫描，或选择“点对点”“原始尺寸”等显示模式。
