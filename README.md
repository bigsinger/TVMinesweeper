# TVMinesweeper · 电视扫雷

面向 Android TV / 电视盒子的经典扫雷游戏，采用纯 Java 与原生 Android Framework。支持 Android 4.3（API 18）及以上系统，无 AndroidX、Kotlin、网络权限或原生动态库。

![大棋盘游戏画面](screenshots/gameplay.jpg)

## 开始游戏

安装 `release` 目录中的最新 `TVMinesweeper-release-版本号.apk` 后启动「电视扫雷」。方向键移动光标，单击 OK 翻开格子，快速双击 OK 插旗。第一步及其周围八格不会有雷。

| 按键 | 功能 |
| --- | --- |
| 方向键 | 移动光标，边界不绕回 |
| OK / Enter 单击 | 翻开；对已开的数字格执行快速展开 |
| OK 快速双击 | 插旗 / 取消旗；双击间隔不超过 280ms |
| 音量 + / − | 插旗 / 取消旗，长按只触发一次 |
| MENU / 设置键 | 难度、音效开关和玩法帮助 |
| 返回 | 关闭弹层，或选择保存并退出 |

音量键由红外直接控制电视时，应用可能收不到事件；此时使用 OK 双击即可。单击会等待约 281ms，以避免双击先误翻格子。

## 游戏功能

- 初级 9×9 / 10 雷、中级 16×16 / 40 雷、高级 30×16 / 99 雷。
- 三栏电视界面：左侧积分榜、相邻的窄信息侧栏、右侧大棋盘。时间、剩雷、难度和操作提示集中在侧栏，为棋盘留出更多空间，方便远距离看清格子和数字。
- 深色背景、青绿色光标、彩色数字与 5% 画面安全边距；三个难度的格子均已放大。
- 首步安全、连片展开、数字快开、错旗提示和结算后查看棋盘。
- 打开所有安全格即可获胜，无需给每个地雷插旗。
- 仅记录真实胜利的本地前八名，沿用 HTML 原型按难度与用时计算积分。
- 自动保存棋盘、光标、难度和音效设置；返回应用时确认继续，不计入暂停时间。
- 移动、翻开、插旗、撤旗、菜单、胜利与失败七种原创短音效，可关闭。
- 默认中文，英文系统自动显示英文。支持遥控器，兼容触摸辅助操作。

```powershell
powershell -ExecutionPolicy Bypass -File tools/build-release.ps1
```

脚本执行 JUnit、release Lint、R8 混淆、签名与构建，自动增加版本号，并把 APK 放入根目录 `release`。项目没有 `.so`，因此交付单个可在 arm64 设备运行的纯 Java APK，不另行构建其他 ABI 版本。

代码只使用 Git `main` 主分支管理。所有 Markdown 文件统一 LF 换行，签名私钥和本机构建缓存不提交。
